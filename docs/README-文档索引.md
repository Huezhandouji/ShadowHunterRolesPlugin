## 三、跨类纪律：身份与引用

1. **不得引用别人给出的字节数 / mtime / SHA256** —— 身份一律现算（`docs/重构进度与交接.md` §4 纪律（身份一律现算））；本文与 `docs/插件文档/日志与证据归档规范.md` 里出现的数字都是"某时点读数"，仅供理解格式。
2. **引用结论时要点到证据**：哪个文件、什么模式（Mode A/B）、什么时点、与哪个基线对比（`docs/最终重构指南.md` §6.3 构建与起服验收（模式必写））。
3. **计划 ≠ 已实现**：本索引只列**已存在**的文件；计划中的产物（如后续阶段的交付小结/验证/评审报告）不预建、不占位。
4. **冻结证据必须入库**：`docs/*.log` 用 `git add -f`；`debug-logs/**` 一律不引用（详见 `docs/插件文档/日志与证据归档规范.md`）。

## 四、维护规则（新增文档时）
