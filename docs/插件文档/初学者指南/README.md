# 初学者指南

## 这组文档给谁看

给**刚开始学编程**的人：你已经会创建变量、给变量赋值、用列表装东西、写 `if`、写循环、写带参数和返回值的函数 —— 就这些。下面这五份文档不会要求你提前懂 Java、也不要求你懂服务端编程。

读完它们的**终点**是：你能自己写出一个角色，进游戏用 `/role set <你的角色id>` 把它选出来，按快捷键能放出技能，快捷栏上有图标。

## 读之前：假定你会什么、假定你不会什么

**假定你会**：变量与赋值、列表 / 数组、`if`、循环、函数（带参数与返回值）、基本算术、字符串。

**假定你不会**（第一次用到它们时，都会用你已经知道的东西打比方讲清楚，不会默认你已经会）：

- Java 的语法细节（`public`、`private`、`final`、`void` 这类短词）；
- 类、对象、继承、接口；
- 事件驱动；
- 多线程；
- tick（游戏循环）；
- Bukkit / Paper 这类服务端编程接口；
- Gradle 构建工具。

读到不认识的词，就按上面「读不懂的时候回到哪一份」的表去翻。
## 推荐阅读顺序

| 顺序 | 文档 | 一句话导读 |
|---|---|---|
| 1 | `01-插件简述.md` | 这个插件在游戏里做了什么、它在服务端里处在什么位置、一个角色由哪些东西组成 |
| 2 | `02-面向对象基础.md` | 读懂代码只需要补六个词：类 · 对象 · 方法 · 字段 · 继承 · 接口，每个都配仓库里的真实例子 |
| 3 | `03-读懂第一段代码.md` | 逐行读一个最短的技能文件；顺带讲清 `tick` 与「事件」；然后动手改一个数值并进游戏验证 |
| 4 | `04-如何创建一个自己的角色.md` | **终点**：从一个空文件开始，写出组件 → 登记角色 → 构建 → 起服 → 进游戏验证 |
| — | `../角色与技能.md` | 参考用：现有角色的全部数值（本文档组不重复它的内容） |

- 只想知道"这插件是干嘛的"：读 `01` 就够。
- 想改点东西但还不想写新文件：读 `01` → `03`。
- 想自己造一个角色：按 `01` → `02` → `03` → `04` 的顺序读。

## 读不懂的时候回到哪一份

| 你卡在这里 | 回到 |
|---|---|
| 不知道这个插件到底做了什么 | `01-插件简述.md` |
| 看到 `class`、`extends`、`private` 这类词发懵 | `02-面向对象基础.md` |
| 看到 `svc()`、`onCast`、`tick`、`@Override` 不知道什么意思 | `03-读懂第一段代码.md` |
| 命令打出来没反应 / 图标没变化 | `03-读懂第一段代码.md` 的「动手改第一个数值」与常见问题 |
| 角色加进去了但选不出来、或服务端报错 | `04-如何创建一个自己的角色.md` 的「规则与常见报错」 |
| 想查现成角色与技能的数值 | `../角色与技能.md` |

## 这组文档不写什么

- 不写完整命令清单与安装部署：看 `../README.md`。
- 不写每个角色的数值与技能效果：看 `../角色与技能.md`。
- 不写内部结构（哪一层调用哪一层）：看 `../架构与组件模型.md`。
- 不写进阶开发规范（命名、纪律、扩展点）：看 `../开发指南-新增角色或组件.md`。

`04` 走完一遍之后，如果你还想知道"为什么代码要这样组织"，那时候再去看 `../架构与组件模型.md` 会轻松很多。
