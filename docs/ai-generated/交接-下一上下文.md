## 7. 本会话血泪纪律（★ 最有价值的部分，务必继承）

1. ★★ **闸门串行化**：多车道共用 `build/` ⇒ 跑闸门前 `Get-Process java` = **0**，且一律 `gradlew test --rerun --no-build-cache **--no-daemon**`（`--no-daemon` **不驻留 JVM**，比"只查进程"更稳）。
2. ★★ **绝不在突变在飞时取基线**（一次被污染的 108 读数就是这么来的）。
3. ★★ **计数会漂 ⇒ 结卡永远重算**；报告任何计数**必须给「模式原文 + 排除规则」**（否则口径无法复核）。
4. ★★ **同文件多批作业 ⇒ 按【内容/锚点】定位，不按行号**（并段会整体下移行号，实测多次）。
5. ★★★ **括号对账只用「逐括号位置压栈配对扫描」** —— 前三法（行内差统计 / hunk 局部 / 配对 diff 加法）**各栽过一次**。判读口径：**行内孤立计数不是缺陷指标**（本件常态是 22/22 两两抵消），**总账差 + 结束深度 + 位置列表才是**。
6. ★★★ **先搬后删 + 逐批复验**：改动前把**删除前原文**（文件 · 行号 · 逐字）追加进存档，**再**编辑。本会话该纪律**五次**抓到真缺口（12 行前半 · `L544` · `L707`/`L708` · `L961` · 10 行 + 2 行）—— 没有它，被删源码会**永久丢失**。
