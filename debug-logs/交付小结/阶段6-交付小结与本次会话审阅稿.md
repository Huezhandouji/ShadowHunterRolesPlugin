- **原则**：**「不占栏位」应当是类型的缺失，不是值的哨兵。**

- **你最后的修正（已采纳为设计规则）**：**除 `setSlot` 这类必须在装配器设置的参数外，其他默认值与组件构造器里提供的值保持一致** ⇒ 组件把自己的名字/描述/图标/冷却/耗能写在**自己的嵌套 `Specification`** 里当默认值，装配点**只写 `setSlot`**。

## 七、仪器陷阱与口径（本会话新增，可直接复用）

| 编号 | 陷阱 | 正确姿势 |
|---|---|---|
| **T-A** | PowerShell `>` 重定向产出 **UTF-16LE** ⇒ 与 blob 做字节/哈希比对**必假失败** | `git cat-file blob <rev>:<path>`，或**直接用 `git grep -f <模式> <rev> -- <path>` 在版本上搜、不落盘** |
| **T-B** | **`git grep` 看不见未跟踪件** ⇒ 恒空 = 假阴性（**队长踩 3 次**） | 用 `--untracked --no-exclude-standard`，或先 `git add` 再 `git grep --cached`，或直读 |
| **T-C** | **git 索引路径大小写敏感**（Windows 亦然），报错却是误导性的 `exists on disk, but not in 'HEAD'` | 路径与磁盘/索引**逐字符**一致；判大小写用 `-ceq` |
| **T-D** | PowerShell `-match`/`-eq` **默认大小写不敏感** | 一律 `-ceq`/`-cmatch` |
| **T-E** | 判据自检的旧侧样本取了"**产物入库的那次提交**" ⇒ 内容已是改写后版本 ⇒ **0 行、无判别力** | 旧侧样本必须取**改写前**的提交 |
| **T-F** | **真空轮**：命令路径写错 ⇒ 比对工具**抛异常后仍写出"通过"报告**（`C` 假为 0），且 ADDED/REMOVED **也都是 0** ⇒ 与有效轮**外观完全相同** | 「应为 0」的判据必须**多条件同时成立**：`ADDED=0 ∧ REMOVED=0 ∧ current 行数=<现算值>`；并给**已知为真的正样本读数** |
| **T-G** | **逐 tick 采样 `getPlayerSanTE` 看不见同 tick 内的两次写入** ⇒ 分辨不出"两次写"与"一次写" | 改用 **`SanTEChangeEvent`**（每次写入都派发）⇒ 直接得到**次序** |

**判据四忌**（四种"看起来在判、其实没判"）：① 裸 `grep` 会命中**被引用的反例**（本会话误报 **4 次**）；② `git grep` 对未跟踪件**恒空**；③ 路径笔误 ⇒ **真空通过**；④ PowerShell 内联 `$(…; $LASTEXITCODE)` **解析失败**（**命令没跑 ≠ 判据不成立**）。
