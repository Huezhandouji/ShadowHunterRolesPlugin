## 一、这个插件是什么

**ShadowHunterRolesPlugin** 是给 Minecraft Java 版（Paper）服务端用的**角色 / 职业系统**插件：给玩家装配一个"角色"，角色由若干**组件**（技能 / 被动 / 主武器）组成，并维护能量、SanTE、生命、阵营、冷却与热键栏图标。

- 主类：`src/main/java/com/shadowHunterRolesPlugin/ShadowHunterRolesPlugin.java`
- 对外 API：`com.shadowHunterRolesPlugin.api.RoleAPI`（在 `onEnable` 注册进 Bukkit 服务表）
- 下游：同工作区的 `SHDFGamePlugin` 对其有硬依赖（`depend: [ShadowHunterRolesPlugin]`）⇒ 服务端上必须先装本插件
- 本插件**没有配置文件**：所有数值写在 Java 里（角色定义 + 各组件构造器）

使用者视角的完整说明（安装、命令、权限、上手）见 **`docs/插件文档/README.md`**。

## 三、构建与运行

```powershell
cd ShadowHunterRoles
$env:GRADLE_USER_HOME = "$PWD\.gradle-work"        # 本地 Gradle 缓存（不入库）

.\gradlew build -x copyPluginJar --console=plain   # 构建（-x：跳过自动拷贝到调试服）
.\gradlew runServer                                # 起本地调试服（Paper 1.21.11）
```

- 构建判定：看 `BUILD SUCCESSFUL` **且**最新 `.class` 的 mtime 已刷新（不要只看退出码）。
- 起服判定：需写明模式（是否安装下游插件），并锚定一个基线日志做"无新增 ERROR"的集合差。
- 安装部署：把 `build/libs/ShadowHunterRolesPlugin-<version>.jar` 放进服务端 `plugins/`；需要 Java 21 与 1.21.11 服务端。
  细节与命令清单见 `docs/插件文档/README.md` §3。

## 五、引用纪律（三条）

1. **身份一律现算**：引用任何文件都要当场给出「字节 + 行数(可选) + 修改时间 + SHA256」，并写明**统计对象与口径**。
2. **引用结论要点到证据**：给出文件、模式（是否安装下游插件）、时点、与哪个基线对比。
3. **历史记录里的旧路径是"当时路径"**：目录调整后，早先记录中出现的路径可能已变化；如需引用，请以**当前实际位置**为准并注明。
