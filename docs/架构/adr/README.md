# 决策记录（ADR）

本目录记录**难以回退、且缺上下文会令人困惑的设计取舍**。每条只写四件事：**背景 / 决策 / 被放弃的替代方案 / 后果（含代价）**。实现细节归 `../架构与组件模型.md`，本目录不重复它。

**收录条件（三条同时满足才写，不满足的不写）：**

1. **难以回退** —— 改主意的代价是实打实的（要动接口、要迁移数据、要重新验证可见行为）；
2. **缺上下文会令人困惑** —— 未来的读者会停下来问"当初为什么这么干"；
3. **是真实取舍** —— 当初确实存在另一条路，是因为具体理由才选了这一条。

**不收录**：容易改回去的写法选择、纯实现细节、"只有一个显而易见做法"的事。
