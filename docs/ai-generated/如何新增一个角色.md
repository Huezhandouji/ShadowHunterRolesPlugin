# 如何新增一个角色（不碰框架）

> **口径**：本件与 [`skills/create-role/SKILL.md`](skills/create-role/SKILL.md) 同源 —— 前者给 AI 用的操作手册，本件给"照着做"的端到端走查。
> **以代码为准** ✗：文中的类/方法/路径全部**现算核对过存在** ✓（核对时点 = 仓库 `HEAD`）；若与代码冲突，信代码。

## 一句话

新增角色 = **写 1~2 个组件**（放 `roleComponent/custom/<角色名>/…`）+ **在 `RoleLoader` 加 3 处**（常量 / `Definition` 行 / builder 方法）⇒ 跑两条闸门 ✓。
**不要**改 `core/` · `api/` · `internal/` · `command/` · `listener/` · `manager/` · `platform/` · `config/` · `event/` · `roleComponent/frameworkLevel/` · `roleComponent/base/` · 构建文件 · `plugin.yml` ✗（详见 skill §1 的硬边界表 ✓）。

## 三步走（真实路径 ✓）

### ① 写组件
```
src/main/java/com/shadowHunterRolesPlugin/roleComponent/custom/<角色名>/skill/<Xxx>Skill.java
src/main/java/com/shadowHunterRolesPlugin/roleComponent/custom/<角色名>/passive/<Xxx>Passive.java
src/main/java/com/shadowHunterRolesPlugin/roleComponent/custom/<角色名>/mainWeapon/<Xxx>MainWeapon.java   ← 需要才写
```
- **技能** `extends Skill`（`roleComponent.base` ✓）；**被动** `extends PassiveSkill` ✓；**主武器** `extends MainWeapon` ✓。
- 构造器三参：`(String id, ComponentServices services, Specification specification)` ✓ + `super(id, services, specification)` ✓。
- **声明值**写在嵌套 `Specification` 里 ✓（照 `RedDeeplySorrowSkill.Specification` 的写法 ✓：显示名 / 描述 / 图标 / 冷却 tick / 耗能 ✓）。
- **状态与冷却归组件自己** ✓：施放成功处 `startCooldown()` ✓；取依赖**只在 `start()`** ✓（不在 `awake()` ✗）。
- 完整可编译骨架见 skill §3 步骤 2 ✓（**逐符号现算自 `custom/red/`** ✓）。

### ② 注册（**唯一允许碰的框架文件** ✓）
`src/main/java/com/shadowHunterRolesPlugin/registry/RoleLoader.java` —— 只加三处 ✓：
```java
private static final String ID_MY_SKILL = "myrole_skill_my";                 // ① 常量（照既有 ID_* 写法）

new Definition("myrole", RoleLoader::myroleBuilder),                        // ② defaultDefinitions() 里一行

private static Role.Builder myroleBuilder() {                               // ③ builder（照 redBuilder() 写法）
    return new Role.Builder("myrole")
            .displayName(Component.text("我的角色"))
            .description(List.of(Component.text("说明")))
            .maxHP(40).baseATK(10).maxEnergy(100).maxSanTE(100)
            .addComponent(ID_MY_SKILL, new MySkill.Specification().setSlot(3))
            .addPassive(ID_MY_PASSIVE, MyPassive::new);
}
```
`Role.Builder` 可用方法（现算自 `core/Role.java:369-560` ✓）：`displayName` · `description` · `addLineOfDescription` · `maxHP` · `baseATK` · `maxEnergy` · `maxSanTE` · `faction` · `icon` · `addComponent(id, spec)` · `addPassive(id, factory)` · `build()` ✓
★ `addComponent` 的 spec **必须** `setSlot(0..8)` ✓；`addPassive` 无栏位 ✓。

## 硬边界速查（每条禁止项都带"为什么" ✓）

| ✗ 不要改 | 为什么 |
|---|---|
| `core/` | 领域核心（`Role`/`RoleInstance`/`RoleInfoImpl`）—— 只读 ✓ |
| `api/` · `internal/api/` | 公开 API 面 + `RoleApiSurfaceTest` 冻结 58 条签名 ✗ |
| `command/` | `/role set <id>` 自动可用 ✓，不需要新指令 ✓ |
| `listener/` | 平台事件入口由框架接线 ✓ |
| `manager/` · `platform/` · `config/` · `event/` | 与角色无关 ✓ |
| `registry/`（除上述 3 处 ✗） | 装载/注册表 |
| `roleComponent/frameworkLevel/` | 框架级服务组件 —— **取用**它们 ✓、不要改 ✗ |
| `roleComponent/base/` | 组件基类 —— **extends** ✓、不要改 ✗ |
| `build.gradle.kts` · `settings.gradle.kts` · `plugin.yml` · `config.yml` | 加角色不需要新依赖/新指令/新权限 ✓ |

**允许**：`roleComponent/custom/<角色名>/…`（你的全部新代码 ✓）+ `registry/RoleLoader.java` 的三处 ✓。
