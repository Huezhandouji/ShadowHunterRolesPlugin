## §7 仪器陷阱（10 族，全部当晚实测）

| 族 | 陷阱 | 正确形态 |
|---|---|---|
| 1 | `Get-NetTCPConnection` 假 0 | 用 `netstat` 按 `LISTENING` 过滤 + TCP connect + 日志读 |
| 2 | `Measure-Object -Line` **只数非空行** | 行数一律 `[System.IO.File]::ReadAllLines` |
| 3 | `Get-Content | Select-Object -Skip N` 在 CJK/无 BOM 文件上**静默漂移/乱码** | 用 `read` 工具或 `ReadAllText(..., UTF8)` |
| 4 | **非 ASCII 路径只许出现在【输出方向】** | `-LiteralPath` 只管 cmdlet 侧；把 CJK 当 **git 参数**喂进去仍**假阴性** ⇒ 让 git 输出清单、只做读取侧比对 |
| 5 | **工具缺失 ⇒ 空比较假 True** | 先证工具可调用（`--version`/存在性）+ **输出非空** + 打印两侧计数 |
| 6 | 登记**续行** ⇒ 解析把上一条的值配给本条 | 机器可解析登记**一行一值** |
| 7 | **生产者侧**管道截断（`Select-Object -First N` 杀原生进程 ⇒ 伪非零退出/伪 stderr） | 先落变量再筛；或用 `-Last N` |
| 8 | **索引可见性**：`git grep` **不搜未跟踪件**；`--untracked` **还会把已跟踪件一并排除**（被忽略子树里恒 0 ✗） | 三件套：`git status --porcelain --ignored` + `git ls-files --others --`（**禁** `--exclude-standard`）+ `git grep --untracked --no-exclude-standard`；归属 `git check-ignore --no-index -v`；追踪态 `git ls-files --error-unmatch`（**两者可同真**） |
| 9 | `.NET` 文件 API 按**进程 CWD**（与 PowerShell 当前位置无关）⇒ 相对路径误报"不存在" | 绝对路径 |
| 10 | **断言/读取自身可靠性**：定长截断（`Substring(0,150)` 打在 2638→3539 字符的长行上）⇒ "存在"读成"不存在" | 判存在**必须用完整行**；先在**已知为真/为负**样本上双向验证断言 |

**额外两条口径铁律**：
- **"自测通过" ≠ "断言集有区分力"** —— 断言必须在**已知为负**样本上报 MISMATCH ✗（`t61-smoke-runner.js` 的 cooldown 三项是**析取**，usage 行同时含 `cooldown/end/restart` ⇒ **真空通过、改 AND 也无效** ✗；修好版 = `91DA741D…` / 8697 B / 182 行）。
- **"搬迁 ≠ 删除"**：普通 grep 下"计数下降"可能是代码**搬进了未跟踪文件**（假进展 ✗）。

## §8 卡务与工具约束（实测）

- 卡面 `verify` 的**每一条**都必须出现在 `commandsRun` 里。
- **证据文件名必须与卡面 `inScope` 逐字一致**（否则 `changedPaths ⊆ inScope` 拒收）。
- `changedPaths` 用**仓库相对**形式（写成工作区相对会被判 `is undeclared`）。
- **卡面契约不可编辑**；终态卡（`completed`/`failed`）**不可回填/改派**；`cancelled`/`failed` 的依赖会**永久阻塞**下游 ⇒ 用**替代卡链**。
- **`inScope` 重叠会被工具拒绝**（`serialize or split`）⇒ 拆分路径。
- 失败尝试会**污染后续尝试**（`changedPaths` 报错后，同一卡的后续 update 需极简 payload）。
- **超范围写入要主动申报 + 队长追认**（先例：`t39`/`t50`/`t65`/`t66`）。
