# 工具缺陷注记 · 数字多重集脚本的「幻影块注释」

> **用途**：登记共享仪器 `.scratch/bot/numeric-multiset.ps1` 的 **string 模式**存在一处系统性误算，并规定引用该仪器输出时必须采用的**口径**。
> **状态**：**已确认、未修复**（仪器本体在**仓库外**、受 `.gitignore` 覆盖 ⇒ 不入库；**不改**是既定处置，见 §4）。
> **同族**：与 `工具缺陷注记-真空断言.md` 属同一族 —— 「**工具会给出一张看起来对、但其实是错的数字**」。真空断言那族是"把未覆盖判成已覆盖"，本族是"把计数算少 1"。

---

## §1 缺陷对象与机制

- **对象**：`.scratch/bot/numeric-multiset.ps1`（工作区根下、**仓库外**；本仓不跟踪）。
- **机制**：该脚本在 string 模式下用块注释正则 `(?s)/\*.*?\*/` 剥除注释。它会把**行注释** `//**顺序说明**` 当成**块注释起点**，从该处一路吞到下一个 `*/`，把区间内的字符串字面量整段漏掉。
- **后果**：`"registered"` 被少算 1 次 ⇒ 该批的 **string 净变化被工具报成 −10，真值 −9**。

## §2 实测（两方独立，互不引用）

| 项 | 读数 |
|---|---|
| after 树幻影区间 | **649..681** 与 **723..746**（后者吞掉 1 个 `"registered"`） |
| before 树幻影区间 | **693..725** |
| `"registered"` 裸计数 / 工具口径 / 先剥行注释口径 | **3/3** · **3/2** · **3/3** |
| string 净变化：工具 vs 真值 | **−10** vs **−9** |
| numeric 模式 | **不受影响** |

**来源与归属**：由 t2（实现）在结卡自查中发现并主动申报（未改共享仪器）；由 t4（独立复核）**独立复现**并给出上述区间与三口径对照。两方读数逐条吻合。

## §3 规定口径（引用该仪器时必须遵守）

凡在证据/报告里引用 `numeric-multiset.ps1` 的 **string 净变化**，必须二选一：

1. **先剥行注释再喂给仪器**（把 `//...` 行注释预处理掉），得到 `3/3`；
2. **显式扣除幻影区间**，并在报告中同时给出**工具口径值与真值**两侧计数，写明差值来源。

**不得**直接把工具输出的 `net` 当真值引用。numeric 模式不受本条约束，但仍须遵守既有的「口径三件齐」（模式 + 定域 + 是否扣除定义/注释/文案）。

## §4 为什么不修仪器本体

该脚本位于**仓库外**的 `.scratch/bot/`（工装区、被忽略）。修它会让**既往证据的可复现性**依赖于一个未受版本控制的脚本版本（本工程对此已有纪律：被引用的仪器版本必须可复原，仪器改动须先跑排练/自检）。两批执行者均**未修改**该脚本，属正确处置。

若将来要把该脚本纳入仓库并修复，须**另行立项**，并同时给出：修复后的自检样本、对既往各批 net 读数的**影响清单**、以及"哪些已冻结结论因此改变"的评估。

### §4.1 ⚠️ 禁止在 src 侧「顺手修注释」

触发串是 `core/RoleInstance.java` 里的一行注释 `//**顺序说明**…`（`/*` 出现在两个斜杠之后）。看上去"给注释加个空格就好了"—— **但不许这么修**：

- 本批 src 是**已冻结代次**（`159512 B / 2026-09-19 12:54:07.286 / 6A249993…`），t2 / t4 / t5 的运行证据**全部钉在这一代上**；
- 改注释 ⇒ 重新编译 ⇒ **jar 的 mtime 与字节都会变** ⇒ 按「制品留档三条规则 1」，该代全部运行证据会被**反转成自相矛盾**（比没有证据更危险）；
- 要动 src，必须先走**为新一代重新取证**的完整流程（重建 → 起服 → 主冻结 → 停机 → 归档），**不能作为"顺手修"夹带**。

⇒ **结论**：F-1 只能修在**仪器侧**（若将来修）；本批的处置 = **只记录 + 规定口径**（见 §3）。

## §5 复现方式

在 `after` 树上按 string 模式各跑一次「裸计数 / 工具口径 / 先剥行注释口径」，三者应分别得到 `3/3` · `3/2` · `3/3`；幻影区间可用「剥块注释后区间是否仍包含目标字面量」直接观察。完整复现步骤见本批说明件 `阶段5-4.4接管-说明.txt` 的 §10.4（t2 侧）。
