三、A1 落点：§4 新增第 11 条（「真空轮」陷阱）
----------------------------------------------------------------
命中行（`git grep -n '真空轮'`）：**L100**（条款标题）· **L106**（关键结论句）。
内容含：机制（`log-delta.ps1` `:29` 对不存在路径 `return @()` ⇒ 空数组解包为 `$null` ⇒ `:46 Compare-Object -DifferenceObject $null` 抛
`ParameterArgumentValidationNullNotAllowed`；`:25 ErrorActionPreference='Continue'` ⇒ 脚本继续执行到 `:56-59` 仍写出 `current=0 / ADDED=0 / REMOVED=0`）
+ **四元组实测**：甲（路径笔误 `runtime\logs\latest.log`）= `anchor 13 / current 0 / ADDED 0 / REMOVED 0`（真空通过）
· 乙（修正为 `run\logs\latest.log`）= `anchor 13 / current 13 / ADDED 0 / REMOVED 0`（有效）
+ 结论：**`C=0` 单独不能区分"有效"与"拿空气比对"**。
