§5 给用户的**四态冒烟清单**（在 25565 装了 SHDF 的外服或本地测试服执行；**需 op**；先 `/role set <roleId>` 选好角色）
| # | 命令（示例：猎人主武器在槽位 0） | 期望现象（证明哪一态） |
|---|---|---|
| 0 | `/role debug cooldown status 0` | 打印 `cooling=false … remainingTicks=0`（**基线**） |
| 1 | 先正常施放一次（左键/右键按角色），再 `/role debug cooldown status 0` | `cooling=true`、`remainingTicks≈声明值`、`declaredTicks=声明值`（**冷却启动**） |
| 2 | 冷却中执行 `/role debug cooldown end 0` | 输出 `returned=true | wasCooling=true | ENDED_BY_COMPONENT dispatched (onCooldownEnd)`；**随后再 `status` ⇒ `cooling=false`**，且**物品立刻变回可放态、可再次施放**（**冷却中 `end()` ✅ + 回调 ✅**） |
| 3 | 不在冷却时执行 `/role debug cooldown end 0` | 输出 `returned=false | wasCooling=false | no-op (was not cooling)`（**幂等、无副作用 ✅**） |
| 4 | 先施放使其进入冷却，再 `/role debug cooldown restart 0` | 输出 `wasCooling=true | RESTARTED dispatched (old segment dropped) | newRemainingTicks≈声明值`；**秒数从新值重新倒数**（**重启顶替 ✅**） |
| 5 | 施放后等到自然到点，再 `/role debug cooldown status 0` | `cooling=false`，且（新增）**冷却表条目已消失** ⇒ 再施放一次仍正常（**自然到期 + O-21 关闭 ✅**） |
> 说明：`status/end/restart` 的 `<slot|componentId>` 既可给 0..8 的**热键栏槽位**，也可直接给**组件 id**（如 `meiqihezi_mainWeapon_juejue`）。
> **回调可观察性**：`onCooldownEnd` 的派发结果目前通过 `end/restart` 的**返回值与文案**间接证明（`ENDED_BY_COMPONENT dispatched` / `RESTARTED dispatched`）；
> 组件侧若未覆写该钩子则无其它可见输出（现有组件均未覆写 ⇒ 预期无额外现象）✓。
