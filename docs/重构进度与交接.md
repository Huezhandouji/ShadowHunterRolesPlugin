## 4. 纪律（不可违反）

- **不申请提权**：approval policy = `ask`，无人应答即失败关闭 → 被沙箱拒绝就**停下、原样留痕、报告"需用户放行"**，不绕道、不换写法硬试。
- **不执行 git 写操作**（`add`/`commit`/`checkout`/`restore`/`stash`/`reset`）—— **提交权在队长**；工作树状态一律用 `git status --porcelain` **现算**。
- **版本/身份一律现算**：以「字节数 + mtime + SHA256」认定；**行号仅辅助、必须附内容片段**；引用实测证据须带**仪器身份 + 运行时刻**。
- **仪器纪律**：改动后**先跑排练/自检**再交付；自检 stub **必须来自实测报文**，不得沿用被测代码的字段假设；被引用的仪器版本**必须可复原**（仓库内受管副本）。
- **收尾纪律**：起服实例与任务一一对应、**用完停服**；起服日志在下次起服前**另存副本**。
