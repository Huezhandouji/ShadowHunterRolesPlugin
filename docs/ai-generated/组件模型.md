## 5. 决策史要点（6 份 ADR 的结论）

| 主题 | 结论 |
|---|---|
| 识别键与状态文案 | **允许组件覆写**：组件可在 `buildItem()` 自己写键与文案；框架不再强制覆盖 |
| 默认画法 | **落在组件基类**（`Skill`/`MainWeapon#buildItem`），描述符**只做声明**、不产出物品 |
| 能力接口合并 | 满足**两条同时成立**才合并，否则分离 |
| 扩展性审查 | 新增/改动扩展点必须过**第三个实例测试** |
| 冷却 | **单一命名空间**：冷却**归组件实例自持**（每个实例一份 `cooldownUntilTick`），框架**不登记、不派发、不落表**；启动入口返回"**本实例是否真的进入了冷却**" |
| 角色信息 | **不做成组件**，归**聚合根 `Role`**；"必须存在"用**装配期校验**而非组件承载 |
| 聚合根归属 | **聚合根 = `Role`（角色模板）**，**不是** `RoleInstance` —— `RoleInstance` 是**每实例容器**，只提供聚合根的**只读服务面**（`roleInfo()`）；`src/main` 全库 **29 行**均按此口径写（`RoleInfo.java:9` · `RoleInstance.java:18`/`:123`/`:128` · `ComponentServices.java:17`） |
