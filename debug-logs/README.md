# debug-logs/ —— 调试日志（**不入库**）

本目录用于放**日常调试日志**：反复运行的服务器控制台导出、机器人基线副本、log-delta 的中间产出、
临时排查用的堆栈/快照等。**内容被 `.gitignore` 忽略**（只保留本 README），避免把噪声提交进仓库。

## 二分法（重要，别放错）

| 类别 | 位置 | 是否入库 | 引用方式 |
|---|---|---|---|
| **调试日志**（可重复生成、非结论） | `debug-logs/调试日志/`（本目录下的分类子目录，2026-09-19 起） | ❌ 忽略 | 不引用；只在排查时看 |
| **冻结证据**（一次性、结论依据） | `debug-logs/测试记录/*.log` | ✅ **必须入库**（`git add -f`，因 `*.log` 被忽略） | **必须带 SHA256 + 时点**；身份一律现算 |

**判定口径**：一段日志若被写进交付小结/验证报告/评审报告当作"结论依据"，它就升级为**冻结证据**，
必须移到 `debug-logs/测试记录/` 并入库；其余一律留在 `debug-logs/调试日志/`，不入库。
