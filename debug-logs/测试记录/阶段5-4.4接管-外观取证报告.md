## §3 仪器与双向自证（A6 / A7 / A8）

### 3.1 采集口径（写清楚"这一列是怎么来的"）

- **外观六维全部取自客户端收到的物品包**：`mineflayer 4.39.0` → `prismarine-item 1.18.0` 的 `components`（1.20.5+ 的 data components 形态），即"玩家真能看到/收到的东西"，不是服务端自述。
- **名字 / 颜色 / 粗体 / 追加文本**由 `prismarine-chat 1.13.0` 渲染（**与 bot 渲染 chat 同一条库路径**）；`name_color_named` 在颜色是字符串时原样保留，是 int 时按 16 色名表归一（本轮实测**全是字符串** `green`/`gray`/`red`，未触发归一路径）。
- **PDC 键**从 `custom_data` 读回；**Paper 实际形态** = 包在 `PublicBukkitValues` 子复合里（见 §3.3 D-3）。
- 每格同时落三种行：`[appearance]`（归一后的六维 + `state`/`derived`）、`[raw]`（**完整**的 `custom_name`/`lore`/`custom_data` JSON，未截断）、必要时 `[identity]`（PDC / 来源分类）。
- `state=` = **按标签声明的目标态**（同轮命令的回执同时在 `[chat]`/`[console]` 里）；`derived=` = **由外观反推**的态（材质+颜色+后缀+lore0 的映射）；两者必须相等（`STATE-CONSISTENCY` 断言 = 0 不一致）。
